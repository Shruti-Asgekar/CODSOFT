# 🐍 Python GUI Projects

A collection of simple Python projects built with a graphical user interface (GUI) using **Tkinter**. These projects are designed to practice Python programming and GUI development.

## 📂 Projects

- 🧮 Calculator
- 📒 Contact Book
- 🔐 Random Password Generator
- ✅ To-Do List
- ✂️ Rock-Paper-Scissors Game

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random Module

